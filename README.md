# Evren Design

Static professional website for design.evrenucar.com. HTML, CSS and two photographs. No build step or dependencies.

Preview: `python3 -m http.server 4176 --bind 127.0.0.1`

Publish through GitHub Pages from the main branch root. Set the custom domain before adding the Namecheap CNAME: host `design`, value `evrenucar.github.io`, TTL automatic. Enable HTTPS after the certificate is issued.
